💻 Samsung is secretly preparing two 'Googbooks'... and the code reveals the codename 'Origin'!

20 November 2026 · Website · Libya Pulse

An examination of the code in the unreleased beta of the One UI 9.5 interface revealed that Samsung is working on two laptops in the 'Googbook' category, despite its absence from the first launch, which included companies such as Acer, Asus, Lenovo, Dell, and HP. The two devices appear in the code as 'origin14iwifi' and 'origin16wifi' — Wi-Fi-only laptops with 14- and 16-inch screens and Qualcomm's 'Snapdragon X Elite' processor.

'Googbook' is a new category of laptops running 'Googbook OS', built on Android, offering a desktop experience similar to ChromeOS but built around the 'Gemini' assistant and integrated with Android phones. Notably, Samsung will likely place its One UI layer on top of the Googbook system — the code even includes instructions to load extra features when an 'Origin' device is detected. Code in Samsung's video editor also pointed to touch and stylus support in the 16-inch version.

Samsung has not announced any details officially, and the name 'Googbook' itself did not appear in the code, so the company may launch the devices under a completely different commercial name. We will likely get a first glimpse when One UI 9.5 is released, in early 2027.

Simply put: Samsung missed the 'Googbook' party, but it is quietly preparing its own version — with its own interface and its own stylus.
