💾 The Magnitude Engine Runs Giant Models from an SSD… An Old Gaming Card Is Enough!

26 November 2026 · Website · TechPulse

An open-source inference engine called Magnitude has revealed a way to run huge AI models on an old gaming graphics card, relying on fast disk storage instead of the card's memory alone.

The engine exploits the way mixture-of-experts models work: each token uses only a small part of the model's weights, so it keeps the shared layers and the most-used experts close to the card, holds another set in system memory, and reads the coldest experts from the storage drive while the card is working.

The project's founder announced on November 20 that the 66-gigabyte Qwen 3.8 Flash Next model runs at 41 tokens per second on a single RTX 3090 with 24 gigabytes of memory, alongside 64 gigabytes of system memory and a PCIe 4.0 drive, in a setup with a 64,000-token context.

The project also claims to run the giant DeepSeek V4.1 Flash model, with 552 billion parameters, at around 40 tokens per second on a single gaming card, using smart caching, prediction of upcoming experts, and disk reads scheduled across layers.

But the figures are still claims from the project's own team and have not been independently measured yet, and the speed depends on most of what the model needs staying in fast memory — the disk alone is not enough if the model asks for many cold weights at once.

Simply put: a gaming card from 2020 and a fast drive might run models that once needed data centers, if the numbers hold up; would you try running a giant model on your old machine?
