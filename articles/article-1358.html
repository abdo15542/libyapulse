🤖 Claude rebuilds Anthropic's interface in Rust.. and saves 70% of CPU without stopping the service!

26 November 2026 · Website · TechPulse

Anthropic has announced that it completed moving its Messages API, the main route through which customers and products such as Claude Code and Cowork reach Claude, from Python to Rust, with the help of Claude's own agents.

The move came after API traffic grew by about 1,800 times between early 2024 and autumn 2026, so Claude wrote the first version of the core request path in about a week, and by May 2026 it was writing more than 80% of the code the company merges overall.

But the real difficulty was not in writing the new code, but in proving that it works exactly like the old one, since the old version kept changing constantly, Claude's responses are not deterministic, and customer requests cannot be read for verification, so the team turned the old API itself into a verification tool.

Advertisement

The method worked by sending the same request through both versions while running the model only once, then comparing the results and sending the differences to Claude agents to fix them in successive verification loops, to the point that the team discovered more than 100 weak tests among about 700 tests ported from Python.

The result is that the new API consumes about 70% less CPU per request, and more than 80% less memory, and cuts the wait time for the first token by about 20%, and public traffic moved to it in September 2026, without the service stopping for a single day or freezing feature development.

Simply put: an AI rebuilt its own home, and the challenge was not the writing but making sure everything works as it did; would you trust code that no human hand wrote at all?

If you were a developer, would you let an AI agent rewrite your entire live system?
