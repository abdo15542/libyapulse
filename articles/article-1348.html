🔑 Microsoft's security updates break sign-in.. and the fix is temporary!

26 November 2026 · Website · TechPulse

Microsoft confirmed that November's security updates may cause authentication problems on some updated devices, preventing users and apps from signing in, at a time when the update itself was meant to close a serious flaw.

The updates close a flaw numbered CVE-2026-118737 in Windows remote communication, caused by a timing weakness in authentication, which could let an attacker without an account run code remotely without any user interaction on unpatched systems.

The updates represent the first stage of new improvements for signing authentication messages using NTLM, meant to reduce exposure to relay attacks, but these same improvements may cause authentication to fail in some apps and external devices, including proxy servers, single sign-on apps and app-wrapping solutions that use NTLM.

The company said the problem appears when an external device does not apply the NTLM protocol precisely, sending a verification message with incomplete or empty information, and advised as a temporary fix changing a setting in the system registry that allows authentication without signing, warning that this fix is short-term and may be removed in future.

The long-term fix, according to the company, is to update the affected product, use a setting compatible with the new signing requirements, or move to Kerberos authentication, while it also confirmed that the same month's updates cause problems activating Windows and with SQL Server database performance, and that it is investigating a printing issue that may break printing of complex-formatted documents.

Simply put: a security update closed a serious flaw, but broke sign-in on some devices, and the temporary fix is a change in the system registry; do you update your system as soon as updates are released, or wait until others complain first?
