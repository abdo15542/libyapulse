🚨 Critical Flaw in Xen Orchestra: An Empty Profile Gives an Attacker Full Admin Rights!

22 November 2026 · Website · Libya Pulse

Vates has warned of a critical flaw in the Xen Orchestra platform, the management console for XCP-ng virtual server clusters, confirming that the flaw is already being exploited in real attacks.

The problem lies in how cookies are read: an attacker only needs to send a cookie carrying an empty authentication token, and the system treats the request as if it came from a logged-in administrator, with no password or valid credentials at all.

Once past authentication, the attacker can perform any action with admin rights, up to running code on server clusters and taking full control of an XCP-ng node with root privileges. The attacks were traced to an address linked to a command server for data-stealing malware, as well as an address over the Tor network.

Advertisement

The company released a fix in versions 6.9.2 and 6.10.1, and advises anyone running the platform to update immediately, not to expose it directly to the internet, to block the malicious address, and to rotate all passwords and secrets if there are any signs of a breach. A second linked flaw was also disclosed, allowing the import of a malicious virtual appliance.

Simply put: two empty tokens open the admin door wide — have you updated your virtual server systems today?
