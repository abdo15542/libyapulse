🔒 Update Chrome Now!

19 November 2026 · Website · Libya Pulse

Google released Chrome 158, which fixes 204 security vulnerabilities, including six critical ones.

The flaws let an attacker run malicious software through web pages, and a researcher from Anthropic discovered two of them with the help of AI.

Simply put, the update reaches you gradually, but you can speed it up from the browser settings and then restart.

Did you update your browser today? Or do you usually postpone updates?
