🎭 A remote code execution flaw in Puppet Enterprise joins the exploited-vulnerabilities list! Deadline: December 1!

23 November 2026 · Website · Libya Pulse

The US Cybersecurity Agency has added a dangerous remote code execution flaw in the Puppet Enterprise platform to its official list of vulnerabilities known to be actively exploited, and given federal agencies until December 1 to fix it.

The flaw carries the number CVE-2026-115731 and a severity score of 9.4 out of 10, and is a flaw in deserializing untrusted data in the report-processing component of the Puppet server — the part that receives agent reports after each configuration run.

Any client holding a certificate signed by Puppet's certificate authority can send a report carrying a carefully crafted data type through a 'PUT' request, so the server executes code with the permissions of the Puppet service account, which could give the attacker access to sensitive data, or the ability to change settings, or disable the service.

The signed-certificate requirement may look like a strong barrier, but it collapses if the certificate authority signs requests without strong verification, as happens when the common autosigning feature is enabled in enterprise deployments — then an attacker on the network can obtain a certificate and exploit the flaw without any real authentication, and access as the service account even gives them the certificate-signing key itself.

The affected versions are Puppet Enterprise 2023.8.0 before 2023.8.13, 2025.0.0 before 2025.12.1, and 2026.0.0 before 2026.0.1, in addition to Puppet Core 8 before 8.22.2 and 9.0.0 before 9.1.3, as well as the open-source OpenVox project.

The developer released the fixes on November 3, in versions 2026.0.1, 2025.12.1, and 2023.8.13, and advised customers to update and restart the server as soon as possible, review autosigning settings, and check the list of signed certificates for unknown nodes, noting that the server listens on port 8140 by default.

Simply put: the server that manages the settings of all your devices could itself be hacked... have you updated Puppet before the deadline?
