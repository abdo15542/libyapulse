🐛 A Critical Apache Roller Flaw Is Being Actively Exploited… Update Urgently!

20 November 2026 · Website · TechPulse

The Apache Foundation warned of a critical flaw in Apache Roller, an open-source Java blog server, numbered CVE-2026-129448 and rated 9.8 out of 10 in severity. The flaw affects versions 4.0.0 to 6.1.4, letting an attacker with no account run commands on the server through an XML-RPC endpoint, because the server converts the sent data before verifying the sender’s identity. Apache confirmed that the flaw is “actively exploited,” and that the fix is in version 6.1.6, while merely stopping the service from the admin panel is not enough, because the bug happens before that setting is read.

Simply put: the server receives a message and unpacks its contents before asking who sent it; and the attacker hides a malicious command inside the message, which runs as soon as it is unpacked — and the update stops this kind of message from being unpacked in the first place.
