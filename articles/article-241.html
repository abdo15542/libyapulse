🔓 'FastUnlock' flaw: the screen reader opens a locked Windows 11 computer!

20 November 2026 · Website · Libya Pulse

A security researcher has revealed a new unpatched flaw called 'FastUnlock', letting anyone holding a locked computer running Windows 11 run programs on it without signing in. The details were published on November 19, and an independent security firm confirmed it by testing the same day. The trick starts at the lock screen: the attacker clicks the 'I forgot my PIN' link, then turns on Windows' built-in screen reader 'Narrator', which opens a hidden window in the background, and navigates it with the keyboard to reach system settings, then device settings, where a USB stick is plugged in to open File Explorer and run a program from it. The program runs under a limited account specific to the lock screen, not with admin privileges, and the attacker needs physical access to the device and an account linked to a Microsoft account. The flaw was tested on Windows 11 version 26H2 with November updates, and there is no fix or official flaw number yet. The flaw does not break 'BitLocker' encryption, because the disk unlocks automatically when the device starts, but it is a reminder that the lock screen alone is not enough protection, and that adding a PIN at startup and shutting down the device when leaving it are the practical protections available now.

Simply put: a tool made to help blind people use computers has turned into a back door; from the lock screen, the attacker reaches the settings, and from there runs a program from an external drive.
